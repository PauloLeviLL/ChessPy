
# ChessPy

Um jogo de xadrez desenvolvido em Python, com interface gráfica em Pygame.

## Tecnologias

- Python 3.13+
- Pygame — interface gráfica
- python-chess — regras e lógica do xadrez
- Stockfish — análise de partidas (futuramente)

## Funcionalidades planejadas

- [ ] Tabuleiro com peças em pixel art
- [ ] Movimentação de peças
- [ ] Validação de movimentos legais
- [ ] Roque, en passant e promoção
- [ ] Jogador contra jogador
- [ ] Integração com Stockfish
- [ ] Identificação de aberturas
- [ ] Análise de partidas
